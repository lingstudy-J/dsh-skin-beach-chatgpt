# 开发笔记：层级契约与踩过的坑

> 这份文件是给改皮肤的人的，不是用户文档。README 里不再收录这些内容。

从 README 移出的原始小节如下。

## 层级契约（踩过的坑，别再踩）
- `backdrop-filter` 会给元素建立**层叠上下文**。DSH 的设置弹框渲染在侧栏内部，一旦给侧栏列加模糊，弹框就被压回侧栏那一层、盖不住对话区。因此侧栏、顶栏、输入卡片都只上半透明底色，**不加** `backdrop-filter`；只有用户气泡（内部没有弹层）保留磨砂。
- 侧栏内部的"透明化"规则显式放过 `[role="dialog"]`、`[role="presentation"]`、`[role="menu"]`、`[data-slot="sidebar.settings"]`，以及任何"包含弹框的祖先"，避免把弹框背景一起清成透明。
- 皮肤**不覆盖** `--dsw-alias-bg-layer-*`、`--dsw-alias-bg-overlay`、`--dsw-alias-button-*`、`--dsw-alias-markdown-code-block` 这些浮层/控件 token；覆盖白名单只有：页面底色、文字色、边框、品牌色、滚动条。`tests/smoke.mjs` 里有对应断言。
- 皮肤自带的浮层（右下角入口 + 设置面板）住在自己的 `.dsh-beach-host` 容器里，并由一个 `MutationObserver` **自愈重挂**：DSH 的 React 重渲染会清掉外部往 `body` 上挂的节点，直接挂 `body` 的表现就是"面板点一下就没了"。容器同时把内部交互的冒泡掐断（不影响宿主自身的全局点击行为），并把 `z-index` 提到远高于官方弹层。
- 滑杆拖动时只写样式，**停手 180ms 后才落盘** `localStorage`：每个像素写一次同步存储会拖住拖动手感。
- **按住滑杆期间，面板里所有按钮 `pointer-events: none`**：松手那一刻不可能"顺带"点中旁边的按钮。这条规则来自一个真实的坑——面板里曾有个"隐藏入口按钮"开关，用户拖着滑杆松手时误触到它，入口被藏起来、面板也跟着关了，表现为"一拖就没了"。
- 皮肤**不提供**会把自己锁死的开关：设置项只在面板里改，入口恒定可达。`tests/smoke.mjs` 有"拖动后面板仍在 / 拖动锁定生效 / 被移除后自动挂回 / 面板里不存在藏入口的开关"的回归断言。
