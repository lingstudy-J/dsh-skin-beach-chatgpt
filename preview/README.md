# 预览图

README 与 `skin.json` 按这些文件名引用，**不要改名**——换图时直接覆盖同名文件即可。

| 文件 | 内容 | 当前状态 |
| --- | --- | --- |
| `light.webp` | 亮色主题下的实际界面 | 已就位（1918×945） |
| `dark.webp` | 暗色主题下的实际界面 | 已就位（1920×945） |
| `skinpanel.webp` | 皮肤设置面板 | 已就位（1920×945） |

换图时的建议：

1. 先把皮肤装好，并在设置面板里按自己的喜好调一遍（设置会持久化，截图更贴近真实使用状态）；
2. 截**整个窗口**——带上左侧栏、输入框和一段对话，比只截壁纸更能说明这套皮肤做了什么；
3. 会话标题、工作目录、路径这类内容记得先遮挡；
4. 宽度 1280 以上、单张控制在 ~200 KiB 内即可，WebP / PNG / JPG 都能被 GitHub 渲染。

`assets/` 里的两张壁纸不是预览图，而是**构建输入**（会被内联进 `lib/client.js`），不要删。
