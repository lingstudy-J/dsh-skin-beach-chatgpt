# 预览图（放安装后的实际界面截图）

README 与 `skin.json` 都按下面这两个文件名引用，**不要改名**——把截图覆盖进去就会自动显示：

| 文件 | 内容 | 建议 |
| --- | --- | --- |
| `light.webp` | 亮色主题下的实际界面 | 1280×720 以上，WebP / PNG / JPG 都可以 |
| `dark.webp` | 暗色主题下的实际界面 | 同上 |

截图建议：

1. 先把皮肤装好，并在设置面板里按自己的喜好调一遍（设置会持久化，截图更贴近真实使用状态）；
2. 截**整个窗口**——带上左侧栏、输入框和一段对话，比只截壁纸更能说明这套皮肤做了什么；
3. 会话标题、工作目录、路径这类内容记得先遮挡。

当前的 `light.webp` / `dark.webp` 是脚本生成的占位图（写着"安装效果截图 · 待替换"），截图就位后直接覆盖即可。
